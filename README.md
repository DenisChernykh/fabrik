# FABRIK — мебельный сайт

Многостраничный сайт мебельной компании с представлением услуг, проектов и условий работы.

## Возможности

- Страницы услуг, компании, контактов и обратной связи.
- Изображения, слайдеры и интерактивные элементы.
- Сборка на Vite, стили Sass и Swiper.

## Инженерные акценты

- Адаптивная многостраничная вёрстка.
- Организация контента и визуальная презентация продукта.
- Компонентное переиспользование стилей и frontend-ресурсов.

## Стек

Vite, Swiper, Sass.
